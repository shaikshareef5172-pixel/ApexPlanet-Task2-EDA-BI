# ApexPlanet Task 2
# Exploratory Data Analysis & Business Intelligence

## 1. Objective

The objective of this project is to uncover patterns, trends and
relationships in the sales dataset using Python, SQL and data
visualization.

## 2. Dataset Overview

The dataset contains sales transaction information including:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Age
- Gender
- City
- Product
- Category
- Quantity
- Unit Price
- Total Sales

## 3. Data Cleaning

The following preprocessing steps were performed:

- Converted Order_Date into date format.
- Missing Age values were handled using the median.
- Missing City values were replaced with "Unknown".
- Completely duplicated rows were removed.
- Original raw data was preserved.

## 4. Descriptive Statistics

Numerical fields analyzed:

- Age
- Quantity
- Unit Price
- Total Sales

Categorical fields analyzed:

- Gender
- City
- Product
- Category

## 5. Visualizations

The following visualizations were created:

1. Age Distribution Histogram
2. Revenue by Category
3. Revenue by Product
4. Monthly Revenue Trend
5. Quantity vs Total Sales Scatter Plot
6. Correlation Heatmap
7. Pair Plot

## 6. SQL Business Questions

Seven business questions were answered using SQL:

1. Top 5 products by revenue
2. Monthly revenue trend
3. Revenue by category
4. Revenue by city
5. Top 10 customers by revenue
6. Revenue by gender
7. Quantity versus revenue by category

## 7. Multivariate Analysis

Correlation analysis was performed between:

- Age
- Quantity
- Unit Price
- Total Sales

Scatter plots, heatmaps and pair plots were used to investigate
relationships.

## 8. Dashboard KPIs

The proposed dashboard tracks:

- Total Revenue
- Total Orders
- Units Sold
- Average Order Value
- Top Product
- Top Category
- Monthly Revenue
- Revenue by City

## 9. Conclusion

The project demonstrates the use of Python, SQL and visualization
techniques to perform exploratory data analysis and answer
business-oriented questions.
